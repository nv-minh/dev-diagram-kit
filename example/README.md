# Worked example — Atlas Re (anonymized reinsurance underwriting platform)

> A *fictional, anonymized* platform modelled on a real NestJS + React codebase — no real names,
> fields, or paths. **Every diagram skill ships one rendered example here**, generated by each skill's
> real pipeline. Start at **[`atlas-re/README.md`](./atlas-re/README.md)** for the full inventory + how
> to regenerate, and [`atlas-re/DOMAIN.md`](./atlas-re/DOMAIN.md) for the domain model.

## What's inside (`example/atlas-re/`)

- **Architecture & data:** `/d2-architect`, `/system-design` (C4), `/erd` + `/d2-erd`, `/dbdiagram`, `/dfd`
- **Behavior:** `/sequence`, `/activity`, `/activity-swimlane`, `/d2-activity`, `/state`, `/bpmn`, `/code-flow`
- **Scope & people:** `/mindmap`, `/journey`, `/timeline`, `/orgchart`, `/usecase-diagram`
- **Cloud (draw.io, real stencils):** `/drawio-azure` (primary cloud) + fabricated `/drawio-aws`, `/drawio-gcp`, `/drawio-databricks`

## Why this example

It exercises the full **node-shape catalog** (`rules/node-shapes.md`): API gateways as hexagons, caches
as `stored_data`, databases as cylinders, queues, CDNs as clouds, pipelines as parallelograms — plus
tech icons (Postgres, Redis, Kafka, nginx…) and the unified `diagram-validate` gate. Regenerate any
artifact with the commands in [`atlas-re/README.md`](./atlas-re/README.md).
